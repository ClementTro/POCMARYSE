# Mode développeur

Lance `npm run mode-dev`. Confirme ensuite en une phrase que le mode développeur est actif : réponses courtes et
techniques, plus de questions systématiques, de captures ni de « oui » avant mise en ligne.

Les contraintes du projet (secrets, RLS, ADR, CI, flux par PR) restent en vigueur.
Pour revenir au mode association : `/mode-association`.
