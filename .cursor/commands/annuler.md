# Annuler la dernière mise en ligne

1. Lance `npm run annuler -- --a-blanc` et explique en mots simples quelle version est actuellement en ligne et
   laquelle sera remise en ligne.
2. Demande confirmation (Oui / Non).
3. Sur un « oui » explicite seulement : `npm run annuler`.
4. Rends compte : la version remise en ligne, ce qu'elle verra, et la nouvelle version qui annule le changement dans le code.
